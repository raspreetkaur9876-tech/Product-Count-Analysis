# Product Count Analysis 📊

## 📌 Project Overview
This project analyzes product counts across different categories using Microsoft Excel. The main goal is to count products in each category and identify the category with the highest count.

## 🎯 Objectives
- Count products by category.
- Practice Excel `COUNTIF` formulas.
- Identify the category with the highest product count.
- Present the results in a clear and organized table.

## 🛠️ Tools Used
- Microsoft Excel
- Sample Superstore Dataset

## 📊 Project Results

| Category | Product Count |
|---|---:|
| Furniture | 2,121 |
| Office Supplies | 6,026 |
| Technology | 1,847 |

**Top Category:** Office Supplies, with 6,026 records.

## 🧮 Excel Functions Used
- `COUNTIF` — Counts records matching a category.
- `MAX` — Finds the highest count.
- `INDEX` and `MATCH` — Identifies the category with the highest count.

## 💡 Key Insights
- Office Supplies has the highest product count.
- Furniture has 2,121 records.
- Technology has 1,847 records.
- Category-wise counting makes it easier to compare product distributions.

- `SAMPLE_SUPERSTORE_FIXED.xlsx` — Excel workbook containing the product count analysis.

## ✅ Conclusion
This project demonstrates how Excel formulas can be used to summarize data, compare categories, and identify the category with the highest count.
